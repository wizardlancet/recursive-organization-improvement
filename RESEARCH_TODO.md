# Research directions not evaluated in this release

The following require new experiments and were not executed for manuscript v3:

1. A Study 2 discover-once / learn-then-stop policy, with acquisition saved after
   commitment and a declared rule for restarting observation under drift.
2. Human reviewers copying agent advice, separately from agent copying of
   human or agent upstream sources.
3. Deployed blind-review private judgments entering memory as operational
   feedback, with the actual measurement and retention costs charged explicitly.
4. Sensitivity to the acquisition ceiling and production amortization scale.
5. Outer selection or revision of observation policies; the existing Study 2
   policies are assigned treatments, not learned procedures.

The README and manuscript describe the currently supported results without
assuming these extensions have been tested.
